## 工作簿结构（10 sheet）

| Sheet | 内容 |
|---|---|
| 00 概况 | 品牌 / 平台 / 条目数 / 总播放 / 粉丝 |
| 01–03 | Instagram / YouTube / Facebook 明细 |
| 04 基准对比 | 同形态播放量（FB 用互动量）中位数分桶 + PI |
| 05 Top-Bottom 30% | 平台内按原始值排序的头尾部内容 |
| 06 归因分析 | 内容形态 × 主题 × 表现 |
| 07 发布节奏 | 周/月发布频次 |
| 08 结论建议 | 规则化自动生成的结论 |
| 09 编码规则 | 打标字段释义 |

## 口径说明

- Instagram / YouTube 有播放量：以**同形态播放量中位数**为基准，PI = 播放量 / 中位数。
- Facebook 无公开播放量：以**互动量（赞 + 评论）中位数**为基准。
- YouTube 长视频日期为列表相对时间折算，标注「中（日期为估算）」，播放量为取整公开值。
- TikTok 仅取粉丝/总赞；LinkedIn / 小红书 / 抖音为登录墙，未取数（不编造）。
